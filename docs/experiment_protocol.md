# 论文实验与数据协议

## 固定实验条件

- 地图分辨率、ROI、作业幅宽、重叠率、膨胀量、速度上限和软件提交号写入每次实验元数据。
- 仿真、离线回放和实车结果分目录保存，原始rosbag只读保留。
- 当前电脑产生的模型、CSV、地图和图表统一放在 `D:\codex_data\artifacts\osh_coverage`，不写入源码目录。
- 每次实车实验前后拍摄障碍物布置，并记录急停、人工干预和不可达区域。

## 场景

1. `plate_shop`：大矩形工位、规则板材堆和中部固定设备。
2. `long_aisle`：长料架、狭窄出口和横向阻断。
3. `irregular`：非规则边界和多个障碍孔洞。
4. `train_skin`：狭长车体周边通道，仅用于仿真迁移。

动态障碍分为短时占道、移动人员替代物、持续占道三类。正式运动实验不得由人员主动进入安全制动区，使用可移动软质障碍物或受控假人替代。

## 方法与消融

- Spiral-STC：独立基线实现或引用固定版本。
- BCD+最近邻。
- BCD+传统掉头。
- 多目标几何规划+全向横移。
- 普通Masked DQN。
- Masked Double DQN。
- 完整系统+实际轨迹动态补漏。

强化学习固定3个随机种子。训练地图和测试地图使用不重叠的种子区间；最终测试至少100张地图。实车每类静态场景至少8次，动态障碍每种至少8次。

## 指标定义

- 覆盖率：实际轨迹扫掠区域与可达ROI交集面积 / 可达ROI面积。
- 漏扫率：可达ROI内未覆盖面积 / 可达ROI面积。
- 重复覆盖率：被时间上分离的轨迹再次扫过的面积 / 已覆盖面积；需固定监测采样和回访间隔参数。
- 空驶距离：跨分区路径和补漏转移路径之和。
- 航向变化：实际航向绝对变化累计值。
- 动态补漏成功：临时障碍移除后，残余连通域在任务结束前被覆盖。
- 不可达面积必须单独报告，禁止从分母静默删除。

## 统计

报告均值、标准差、95%置信区间和每次原始结果。先检查分布；成对结果不满足正态性时使用Wilcoxon符号秩检验，并同时报告效应量。RL若未显著优于启发式，保留结果并停止扩展网络结构。

## 验收门

- 地图配准：位置RMS ≤0.10 m，航向误差≤2°。
- 可达区域实际覆盖率≥98%。
- 正式实验零碰撞、零未解释急停。
- 持续阻塞区域经过两次失败后进入“暂不可达”，不计入已覆盖。
- RL不得改变碰撞检查结果或关闭原厂避障。
