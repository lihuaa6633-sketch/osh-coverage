# 十个月执行台账

| 月份 | 可验收输出 | 决策门 |
|---|---|---|
| 1 | 接口审计记录、双网口、电源原理图、支架图、低速运动报告 | 急停/避障/坐标未确认不得继续 |
| 2 | Airy点云/IMU rosbag、内外参、时间同步报告 | 点云和IMU频率稳定 |
| 3 | KISS-ICP+RTAB-Map地图、回环与漂移评价 | 至少一个实验室场景稳定建图 |
| 4 | 0.05 m二维地图、双地图配准、独立验证轨迹 | 若不达标，转二维SLAM备用链 |
| 5 | BCD、最近邻、传统掉头、全向横移及离线对比 | 实际覆盖率先达到98% |
| 6 | MoveBase分块执行、静态实车闭环、取消/故障测试 | 零碰撞后才扩大场景 |
| 7 | DQN/DDQN三种子模型、动作掩码和课程学习消融 | 无稳定收益则冻结RL范围 |
| 8 | 实际轨迹监测、动态补漏、两次重试状态机 | 动态障碍移除后能够补扫 |
| 9 | 100张离线地图、每场景≥8次实车、统计结果 | 结果和原始数据一一对应 |
| 10 | 论文、代码版本、配置、数据索引、答辩演示 | 不再引入新算法 |

写作与实验并行：第2–3月写平台与建图，第4–5月写建模，第6–7月写几何与RL，第8–9月写系统和实验，第10月只做收敛、复核和答辩准备。
