# 硬件、网络与安全集成清单

## 上电前

- Airy工作电压9–32 V，底盘扩展口为48–54.7 V：使用隔离DC-DC、输入输出保险和独立断电开关，禁止直接连接。
- 核对DC-DC额定输入范围、持续功率、启动浪涌、极性、接地和线束温升。
- 雷达安装面平面度、紧固力矩、线缆余量和散热按Airy手册执行；防护罩360°视场内不得遮挡。
- 支架完成静力校核，目标一阶模态大于50 Hz；外参标定完成后做防松标记。
- 急停按钮、暂停/继续按钮、灯带、扬声器和原厂避障必须正常。

涉及电源结构修改时由具备电气资质的人员复核，本仓库不替代电气安全设计。

## 双网口

| 设备 | 默认地址 | 建议上位机接口 |
|---|---|---|
| Woosh底盘 | `169.254.128.2` | `enp1s0`，同链路本地网段 |
| Airy | `192.168.1.200` | `enp2s0`，例如 `192.168.1.102/24` |

不要在同一接口同时配置两个设备。确认UDP 6699、7788、6688未被防火墙阻断，并使用 `tcpdump`/Wireshark检查包率。

## 分阶段运动测试

1. 架空或断开驱动状态下验证话题、坐标正负方向和急停。
2. 隔离区内以不高于0.20 m/s验证前进、后退、旋转、横移。
3. 以不高于0.30 m/s跑单个矩形分区和取消动作。
4. 验证地图双向变换后，才允许分块执行完整覆盖路径。
5. 正式实验建议不高于0.60 m/s；提升速度必须重新评估制动距离和最小间距。

## 场地限制

- 只在硬质、平整、干燥、无油水和金属粉尘的室内地面使用。
- 固定围栏和警示线外安排一名急停监护人。
- 禁止关闭原厂避障；禁止把规划器的“可达”解释为功能安全认证。
- 手册中越障/坡度和续航数字在不同章节不一致。使用保守值，并把实测结果列为平台标定数据。
